# End-to-End Data Analytics Project

## Overview
An end-to-end data analytics project focused on transforming raw data into actionable business insights using Python, SQL, and Power BI.

## Dataset
- **Source:** Customer Behavior Analysis
- **Format:** CSV / Excel
- **Objective:** Identify trends, patterns, and key business insights.

## Tools & Technologies
- **Python:** Pandas, NumPy
- **SQL:** PostgreSQL
- **Power BI:** Interactive dashboards and KPI visualization
- **Gamma:** Presentation creation

## Project Steps
1. **Data Loading:** Imported the dataset into Python.
2. **EDA:** Explored distributions, trends, and relationships.
3. **Data Cleaning:** Handled missing values, duplicates, and inconsistencies.
4. **SQL Analysis:** Queried data to answer business questions and calculate KPIs.
5. **Dashboard:** Built an interactive Power BI dashboard.
6. **Reporting:** Summarized key findings, recommendations, and insights in a report and presentation.

## How to Run
1. Clone this repository.
2. Install dependencies using `pip install -r requirements.txt`.
3. Run the Jupyter Notebook for data analysis.
4. Execute SQL scripts in your database.
5. Open the `.pbix` file in Power BI Desktop.
